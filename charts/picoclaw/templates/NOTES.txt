Gateway is listening on port {{ .Values.config.gateway.port }}.

{{- if .Values.client.httpRoute.enabled }}

Client is accessible via HTTPRoute:
{{- range .Values.client.httpRoute.hostnames }}
  http://{{ . }}/
{{- end }}

{{- else }}

HTTPRoute is disabled. To expose the client enable httpRoute in values.yaml:
  client:
    httpRoute:
      enabled: true
      parentRefs:
        - name: gateway
          sectionName: http
      hostnames:
        - picoclaw.example.com
      rules:
        - matches:
            - path:
                type: PathPrefix
                value: /

{{- end }}

To port-forward the client locally:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "picoclaw.fullname" . }} {{ .Values.client.port }}:{{ .Values.client.port }}

To view logs:
  kubectl logs -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "picoclaw.name" . }}" -c picoclaw-gateway -f
  kubectl logs -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "picoclaw.name" . }}" -c picoclaw-client -f
